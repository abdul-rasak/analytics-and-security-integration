# Analytics and Security Integration – Inventory Management Software

## Feature 1: Stock Reorder Analysis

### Description
Stock Reorder Analysis is an analytics feature that helps the system identify products that need to be restocked.

### How the Feature Works
The system monitors the quantity of each product in the inventory. When the quantity of a product falls below its set minimum stock level, the system identifies it as needing a reorder. The information can be displayed to the administrator so that new stock can be purchased before the product runs out.

---

## Feature 2: Automatic Logout

### Description
Automatic Logout is a security feature that automatically signs a user out after a period of inactivity.

### How the Feature Works
The system monitors how long a user has been inactive. If the user does not perform any activity for a specified period, the system automatically logs them out. The user must log in again to continue using the system.

This helps protect inventory information when a user leaves a computer unattended.
