# Analytics and Security Integration Features

## Feature 1: Low-Stock Trend Analysis

### Description
Low-Stock Trend Analysis is an analytics feature that monitors products that frequently reach low stock levels. It helps the business identify products that may need more frequent restocking.

### How the Feature Works
The system checks the stock levels of products over time and identifies items that regularly fall below the minimum stock level. It can display these products in a report, allowing the inventory manager to plan restocking before the products run out.

## Feature 2: Login Security and Failed Login Alerts

### Description
Login Security and Failed Login Alerts is a security feature that protects the inventory system from unauthorized access.

### How the Feature Works
Users log in with their registered username and password. The system records failed login attempts and can alert the administrator when there are several unsuccessful attempts. This helps detect possible unauthorized attempts to access the inventory system.
